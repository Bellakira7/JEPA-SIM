# Paper figures used in the README

These images are raster crops of the accompanying **JEPA-SIM: Render-Free Closed-Loop Driving
Simulation** paper supplied by the authors.

- `method-figure2.png`: Figure 2, PDF page 3; closed loop, layout conditioning and training.
- `interfaces-figure-s2.png`: Figure S2, PDF page 13; in-house, UniAD and OpenScene injection points.

Both crops were rendered at 240 dpi, with captions transcribed/contextualized in the root README.
Figure 2 illustrates geometric layout conditioning; Appendix A.3.1 details UniAD's pixel-unshuffle
adapter. Figure S2 shows each driving model's feature injection point.
